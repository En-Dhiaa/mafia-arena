# دليل وقواعد لعبة Mafia Arena الرسمية
## Official Mafia Arena Game Rules

---

## 1. ملخص الفرق
- **فريق المافيا:** زعيم المافيا، مافيا، مافيا التسكيت، مافيا القنبلة.
- **فريق المواطنين:** الدكتور، المحقق، القناص، المواطن الشاب، العمدة، المواطن.
- **الشخصيات المحايدة:** الحكم (Arbiter).

## 2. جدول القدرات والشروط
| الشخصية | الفريق | القدرة الرئيسية | الشروط الخاصة |
| :--- | :---: | :--- | :--- |
| **زعيم المافيا** | مافيا | اختيار الضحية وصوته حاسم | له سلطة الفيتو عند الاختلاف |
| **المافيا** | مافيا | المشاركة في القتل الليلي | تصويت مشترك مع الفريق |
| **مافيا التسكيت** | مافيا | تكميم فم لاعب نهاراً | الهدف يصوت لكن لا يتكلم |
| **مافيا القنبلة** | مافيا | انفجار انتحاري عند الإقصاء | يسحب لاعباً آخر برفقته |
| **الدكتور** | مواطن | حماية لاعب من القتل ليلاً | يمنع الموت إذا هاجمته المافيا |
| **المحقق** | مواطن | فحص هوية مشتبه به | يتلقى تقريراً سرياً (مافيا أم بريء) |
| **القناص** | مواطن | رصاصة ليلية قاتلة | طلقة واحدة أو طلقتان حسب الإعداد |
| **المواطن الشاب** | مواطن | الانتقام عند الإعدام نهاراً | يسحب مشتبهاً به معه للقبر |
| **العمدة** | مواطن | صوته يزن 3 أصوات | قوة ترجيح حاسمة في الاقتراع |
| **المواطن** | مواطن | التحليل والنقاش والتصويت | الدفاع عن المدينة بالمنطق |
| **الحكم** | محايد | الفصل في حالات التعادل | الحفاظ على ميزان العدالة |

## 3. شروط الفوز
- **فوز المواطنين:** يتم فور القضاء على جميع أفراد المافيا.
- **فوز المافيا:** يتم فور تساوي عدد المافيا الأحياء مع عدد المواطنين الأحياء.
